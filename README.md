# GuesserGame
Guesser Game is a simple, interactive console-based number guessing game written in Java. The computer generates a random number within a defined range, and the player must guess it within a limited number of attempts. After each guess, the program provides feedback whether the guessed number is too high or too low, helping the player narrow down the correct answer.

Installation
Clone this repository or download the source files:
GuesserGame.java
GameRunner.java
Save the files to a directory of your choice.

How to Run
Using Command Line
Open your terminal or command prompt.
Navigate to the directory containing the Java files:
cd path/to/your/directory

Compile the Java files:
javac GuesserGame.java GameRunner.java

Run the game:
java GameRunner
Or directly:
java GuesserGame
